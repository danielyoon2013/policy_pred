# Findings log

Research trail for the policy-belief project, for the paper. One folder per experiment, grouped by
month. Each experiment folder is a self-contained mini-report: a `README.md` (question · method ·
results · caveats), a `figures/` dir, and a `tables/` dir. Newest on top.

| Date | Experiment | One-line result |

Each report is reproducible from the committed `analysis/` scripts + the local eval archives — see
the artifacts section at the bottom of each report.
